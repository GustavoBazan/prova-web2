# Games Store

Portal de vendas de games feito com HTML, CSS e JavaScript puro.

## Paleta

-paper #FFFFFF Fundo da página
--ink #181A2A Texto principal e identidade da marca
--slate #6B7280 Texto secundário (descrições, metadados)
--mist #F3F4F6 Superfícies suaves (cards, campos)
--line #E5E7EB Linhas e bordas
--accent #6D28D9 Marca, botões de ação e destaques
--price #059669 Preços e selos de oferta
--star #F59E0B Estrelas de avaliação

## Fontes

- **Lucida Sans**: logotipo e títulos
- **Inter**: navegação, textos, metadados e botões

Ambas do [Google Fonts](https://fonts.google.com).
